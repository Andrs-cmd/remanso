# Remanso

App para bajar el estrés y la ansiedad con mecánicas interactivas: respiración guiada, burbujas, luz líquida, jardín zen, gota líquida, Liquid Ether y unir puntos.

- **Web:** https://andrs-cmd.github.io/remanso/
- **Android:** HTML5 + Capacitor 6 (`npx cap sync android` y `android\gradlew.bat assembleDebug`).

Cada mecánica es un archivo en `www/js/mecanicas/`; el catálogo está en [MECANICAS.md](MECANICAS.md).

> Remanso ayuda a bajar la tensión del momento, pero no reemplaza a un profesional de salud mental.
